Loupe

Comment-tree analysis for Bilibili — a Chrome extension. 中文名：Loupe · 评鉴。

What Loupe is

Loupe is a browser extension for Bilibili (bilibili.com) that reads the public comment section of a video, rebuilds the reply trees, and visualises who replied to whom. It also exports reports and, only when you explicitly enable it, can send a budget-limited comment excerpt to an AI endpoint that you configure yourself.

  • Reads public comments only — no passwords, no e-mail, no private messages.
  • Runs entirely in your browser. Loupe has no server: there is no account, no sign-in, and nothing to log into.
  • All data stays on your machine (IndexedDB + chrome.storage.local).

Chrome extension

The published extension is Loupe · 评鉴 on the Chrome Web Store. Everything on this page can be read without logging in; the extension itself needs no account either — it uses the Bilibili session your browser already has, exactly like visiting the site.

Why this site is the homepage of an OAuth client

Loupe's release tooling uses a Google OAuth client with the single scope https://www.googleapis.com/auth/chromewebstore to upload new versions of the extension to the Chrome Web Store through the official API. That client is used only by the developer's own machine:

  • It does not access any end user's Google account or data.
  • It cannot read or write anything except the developer's own Chrome Web Store item (upload + publish).
  • The refresh token lives in a local .env file on the developer's computer.
