Loupe

A Chrome extension for Bilibili comment analysis.

This page is the home page of the application “Loupe”. No account is needed and there is nothing to log in to — everything on this page is public and readable by anyone.

What Loupe does

Loupe reads the public comment section of a Bilibili (bilibili.com) video, rebuilds the reply trees (who replied to whom), and visualises them as an interactive graph. It can also produce a text report of a comment section, and — only when the user explicitly turns it on — send a size-limited excerpt of the comments to an AI endpoint that the user configures themselves.

  • Purpose: make long comment sections readable — thread structure, participants, reply depth.
  • Reads public comments only. No passwords, no e-mail, no private messages.
  • Runs entirely in the browser. Loupe has no server and no account system.
  • All fetched data stays on the user's machine (IndexedDB and chrome.storage.local).

How it is distributed

Loupe is published on the Chrome Web Store as a Chrome extension. To upload new versions, the developer uses Google's Chrome Web Store API with an OAuth client that has exactly one scope: https://www.googleapis.com/auth/chromewebstore. That client is used only from the developer's own computer, cannot read any end user's Google account, and cannot touch anything except the developer's own store item (upload + publish). Its refresh token is kept in a local file on that computer.

What Loupe does not do

  • It does not collect, sell, or share personal data.
  • It does not use Google APIs to access user data.
  • It does not generate images of any kind, and has nothing to do with AI-generated intimate imagery.
