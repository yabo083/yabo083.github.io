Loupe · 评鉴 隐私政策 / Privacy Policy

生效日期：2026-10-11（2026-10-30 修订）｜ 适用：Loupe · 评鉴 扩展（Chrome / Edge / Chromium）与本网站的 OAuth 客户端

Loupe · 评鉴（以下简称「本扩展」）是一个运行在你浏览器本地的评论区分析工具。本政策说明本扩展处理哪些数据、数据流向哪里、以及你的控制权。

一、本扩展不收集、不上传、不出售你的数据

  • 本扩展没有自己的服务器。所有抓取、建树、统计与可视化都在你的浏览器内完成。
  • 本扩展不收集任何个人信息，不出售或共享数据给第三方，不做任何用户行为分析或广告用途。
  • 本扩展没有账号体系，不需要登录本扩展，也不要求你提供姓名、邮箱或任何身份信息。

二、本扩展处理的数据

  • 公开评论内容：在你主动触发分析时，本扩展使用你当前浏览器的登录态从哔哩哔哩（bilibili.com）读取评论区数据，包括评论正文、作者昵称与等级、时间、点赞数、表情与图片。这些数据仅在你本地处理并缓存于本机浏览器，不会离开你的设备，除非你执行下述「AI 解读」操作。
  • 本机缓存与设置：抓取结果缓存在本机 IndexedDB，偏好设置保存在 chrome.storage.local；关闭浏览器不会使它们离开你的设备。
  • 你主动发起的写操作：当你点击点赞、回复或发表评论时，本扩展在哔哩哔哩页面上下文内，使用你当前会话的登录态与 CSRF 令牌（bili_jct）调用哔哩哔哩官方接口。该令牌只在这一次请求体内即时使用，不保存、不跨页面传递、不进入日志、快照或缓存键。写操作与你直接在 B 站网页上点赞、发评使用同一套身份与接口。

三、数据流向（唯一例外：AI 解读）

  • 本扩展默认不调用任何外部服务。仅当你明确开启并点击「AI 解读 / 诊断」时，才会把经过预算限制的评论摘录发送到你自己配置的 OpenAI 兼容端点（Base URL 与模型由你填写）。
  • 该端点由你自备，本扩展不提供默认端点、不经手或中转请求。发送前请确认你选择的端点及其服务方的数据处理条款。
  • 你配置的 API Key 保存在本机 chrome.storage.local，不进入历史快照，也不会上传到本扩展作者或任何第三方。

四、本扩展如何读取哔哩哔哩页面

  • 为呈现「替换评论区」功能，本扩展会在你开启开关后隐藏原生评论区节点并挂载自绘评论区。本扩展仅读取公开评论数据，不读取你的密码、邮箱、私信或任何与评论分析无关的账号信息。
  • 扩展被重载或更新后，本扩展会停止并向你提示刷新页面以恢复。

五、本网站的 OAuth 客户端

  • 本网站是 Loupe 发布流程所用 Google OAuth 客户端的首页。该客户端只有一个权限范围：https://www.googleapis.com/auth/chromewebstore。
  • 它只被开发者本人用于通过 Chrome Web Store API 上传与发布 Loupe 扩展的新版本；不读取任何终端用户的 Google 账号数据，也不能访问开发者自己条目之外的任何内容。
  • 其 refresh token 保存在开发者本机 .env 文件中，不进版本库、不上传、不共享。本网站本身不设置 Cookie、不接入统计或广告脚本。

六、你的控制权

  • 随时撤销：在扩展图标的设置面板里关闭开关，或在 chrome://extensions 中卸载本扩展，即可停止全部行为；历史与缓存会随卸载从本机移除。
  • 清除数据：在工作台「历史」中删除快照，即可清除本机保存的评论数据。

七、变更

本政策更新时，会在本页面修订生效日期。重大变更会通过扩展更新说明提示。
